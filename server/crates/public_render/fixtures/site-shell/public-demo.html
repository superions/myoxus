Long Documentation Fixture

This fixture validates public rendering with long prose, code, navigation, lists and unsupported blocks without loading Web, Admin, editor or workspace bundles.

Overview

Public pages should read like documentation, not like an editor preview. The line length, table of contents and adjacent navigation must remain stable across desktop and compact viewports.

  • Readable typography with native list markers.
    • Nested editor lists remain nested in public HTML.
  • Consecutive items share one semantic list.
  1. Numbered editor lists use native ordered markers.
