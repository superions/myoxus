# Getting started

[Documentation](../../README.md) / [Operations](../README.md)

Set up a Myoxus installation in four steps, from topology and sizing to daily
operations.

The self-hosting beta entry combines the Rust server, Browser Web and Admin.
Check [download availability](../../user/downloads.md) before selecting a
version. Existing Forgejo distributions and the first public GitHub beta have
separate publication states; a Stable channel label does not promise production
maturity. Keep coordinated backups and follow the documented upgrade route.

1. [Choose a deployment](./installation-decision.md): installation methods,
   topology diagrams and server-package status.
2. [Size the installation](../deployment/sizing.md): estimated CPU, RAM and
   storage for 10, 50, 500 and 5,000 users.
3. [Install Myoxus](./installation.md): prerequisites, startup and first login.
4. [Configure and protect the installation](./start-here.md): organization,
   authentication, integrations, backups and monitoring.

The [Deployment section](../deployment/README.md) contains the detailed
installation and update procedures for each topology.
