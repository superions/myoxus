tasks, or explore the guides below to see how Myoxus fits your work.

Das Handbuch erklärt die Myoxus-Oberfläche: Dokumente und Blöcke, Ordner,
Sammlungen und Tags, Datenbanken, Zusammenarbeit, Export und Wiederherstellung.
Die Abbildungen zeigen die helle Oberfläche in der jeweiligen Sprache.

The guide covers the Myoxus interface: documents and blocks, folders,
collections and tags, databases, collaboration, export and recovery.
Screenshots use the light theme and match each edition’s interface language.
