# Myoxus Icons Provenance

`@myoxus/icons` is the global icon entry point for Myoxus application UI,
editor UI, and generated platform brand assets.

## Source Of Truth

- UI glyph geometry is generated by `@virgultum/icons` and re-exported through
  `@myoxus/icons/react` and `@myoxus/icons/lit`.
- React exports are wrapped by `scripts/build-facade.mjs` so app surfaces can use
  a single `size`-aware icon prop shape.
- The low-level generator contains semantic and distinctness contracts for
  directional actions, UI states, domain/navigation icons, and small-size
  silhouettes. The facade must never paper over a wrong glyph by aliasing it
  under a nicer name.
- App, favicon, tray, and installer icon files are generated by
  `scripts/build-assets.mjs` from original Myoxus vector sources.
- The generated app icon foreground uses the fixed B2-3 raised-whisker mascot
  refinement selected for Myoxus app identity. It is not a runtime-customizable
  app/server branding surface.
- Browser favicons use the same fixed B2-3 mascot as a transparent, unframed
  browser icon. Electron and installer icons keep the channel-specific framed
  app-icon background.
- The bundled static `product-mark.svg` fallback mirrors the same B2-3 geometry
  for the runtime `productMark` slot; when served through `/style/*`, it remains
  part of the runtime app/server branding contract.
- The About Myoxus screen uses the fixed canonical wordmark source
  `assets/branding/myoxus_text.svg`. Removed hashed abstract line-mark assets
  and retired combined runtime-logo copies are blocked in generated static
  bundles.
- Generated UI and platform artifacts are committed to the repository. Ordinary
  builds verify the committed facade; explicit `generate:*` scripts update
  artifacts when the icon source changes.

## Quality Gate

An exported icon is only accepted when it is available, has explicit provenance
and licensing, and is visually/semantically recognizable at product sizes. For
action icons this includes directionality: import, export, upload,
external-link, create, insert, and move icons must not render as interchangeable
arrows. For state icons this includes distinguishable checked, unchecked,
mixed, selected, unselected, visible, and hidden states.

UI glyphs are schematic single-color symbols. The generated React/Lit facade
must not contain tonal `opacity` layers or grey Duotone fills. Compatibility
names such as `*DuotoneIcon` may remain exported, but their geometry must still
render as single-`currentColor` Myoxus glyphs.

External open-source iconsets may be used as reviewed geometry sources behind
the facade when their licenses and mappings are explicit. Product code must
still import only `@myoxus/icons/react` or `@myoxus/icons/lit`.

The retained historical Top-50 decision aid records the Phosphor/Tabler
comparison and keeps both MIT notices. Its temporary generator and Phosphor
dependency were removed after the Tabler selection. The facade continues to
consume generated glyphs; the maintained Tabler-only review and generation
workflow remains available.

The 2026-07-17 review selected Tabler and accepted the explicit Top-200 mapping
in `virgultum/icons/src/mappings/tabler-top-200.json`. The reproducible obvious-mapping
pass in `virgultum/icons/src/mappings/tabler-obvious.json` adds same-name glyphs,
technical style/brand/panel variants, and explicit semantically equivalent
aliases. The focused remainder review in
`virgultum/icons/src/mappings/tabler-open-review.json` selects further Tabler
geometry and explicit Myoxus fallbacks. React and Lit consume the same generated
geometry, and Tabler remains a pinned build-time input rather than a product
runtime import. The current mapping inventory is documented in
`docs/dev/myoxus-icon-system.md`.

When glyph geometry changes, regenerate `@virgultum/icons`, regenerate the
Myoxus facade, run both icon checks, and visually review a full gallery of all
exports plus the active frontend imports at 36px, 18px, and 14px.

Full-gallery reviews are persisted as audit artifacts. The 2026-05-09 export
review is `virgultum/icons/visual-audit-2026-05-09.json`; it categorizes all
733 exports with the strict categories `ok`, `review`, and `fix`. Icon-quality
patches are accepted only when the audit ends with `summary.fix === 0`.

## Compatibility

`@virgultum/icons` remains the low-level generated glyph package. Application
code should import icons from `@myoxus/icons/react` or `@myoxus/icons/lit`.

Persisted icon data uses the value `"myoxus-icon"`. Active code must use
`IconType.MyoxusIcon`; legacy product-icon API names are blocked by the icon
boundary check.
